使用 Directory Studio

1. 在扩展详情开启「允许访问文件网址」。

2. 从外部打开本地目录、文本或图片，插件会自动转入工作台。HTML、PDF 和未知文件保持浏览器原生行为。

3. 编辑后可下载副本，副本不会覆盖原文件；Ctrl+S 或「保存原文件」可选择并授权同一个原文件。也可以通过「选择文件并授权编辑」打开文件。

文件网址权限负责读取，文件选择器授权负责写入。插件仅原位保存 UTF-8 文本；磁盘发生外部修改时会停止保存。

默认在当前窗口的工作台内切换文件；已打开列表可搜索文件名和路径，切换保留未保存编辑、撤销和阅读位置。关闭文件前请保存修改。

路径及收藏保存在本机；不会上传或持久化正文。取消勾选「自动接管」可暂停。需要独立查看时，点击「在独立标签页打开」或 Ctrl/⌘ 点击链接；不会自动创建 Chrome 标签组。

更改扩展权限、停用或重新加载插件可能直接关闭工作台，请先保存编辑。系统文件选择器不提供完整路径，首次授权保存时需确认选中原文件。
